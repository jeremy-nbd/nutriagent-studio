项目来源与个人贡献

本项目从营养分析和报告交付的工程问题出发，独立编写演示实现。未复制原业务仓库源码、客户资料或商业报告。原业务项目中的团队能力与个人贡献，需要在正式求职材料中分别核实。

MODEL CONNECTION

连接你的模型

默认无需密钥即可体验示例。真实模式支持兼容 Chat Completions 和工具调用的服务。

  1. 将项目根目录的 .env.example 复制为 .env。
  2. 设置 MODEL_BASE_URL、MODEL_NAME 和 MODEL_API_KEY。
  3. 重新启动 npm run dev，页面将显示“真实模型”。
密钥只保存在服务端，不发送到浏览器。真实模型模式仍使用本项目合成数据；失败恢复场景固定采用示例编排。
