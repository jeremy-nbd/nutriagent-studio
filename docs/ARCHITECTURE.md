# Python 架构

入口 `python3 run.py`，全部服务端功能由 Python 标准库实现。`public/` 继续使用原生 JavaScript 交互，HTTP JSON 字段保持兼容，不依赖 Node 服务。

## 真实饮食输入

`nutrition.py` 验证图片类型/大小并调用 VLM，或调用 LLM 处理文字。模型只提供食物、候选克数和每100克参考营养；Python 做格式与合理范围校验、确定性换算。草稿确认后才参与日周统计。未知份量为 null，不能当0保存。

记录沿用 draft / saved / deleted 状态及 revision。并发识别复用 Future，重复确认返回同一记录；修改/软删除在进程锁内执行版本检查和原子文件更新。两个并发模型调用槽位共享于识别与总结，过载立即报错。

周范围为北京时间周一至周日，日均分母为有记录日期数。总结提供确认记录与计算事实给模型，校验观察的记录引用，生成期间数据变化拒绝旧结果。引用存在校验不能替代语义证据验证。

## 工程演示

`agent.py` 实现六种工具；示例编排和模型编排共用工具入口。报告必须先计算和校验；米饭份量修订仅接受用户本轮明确输入，并防止重复折半。模型上限六轮/十二次工具，完成、澄清或失败后停止。

`server.py` 的后台任务逐事件保存 JSON。SSE 按事件序号续接，使用条件变量等待新事件，完成后关闭。服务重启把运行中的旧任务转为失败，保留中间分析和校验供恢复。历史 JSON 格式兼容，固定示例内容从原独立项目提取到 demo.json。

## 模型与存储边界

`core.py` 统一加载 .env（进程环境优先）、LLM/VLM 与旧 MODEL 变量。urllib 请求具有超时、响应大小限制，不跟随重定向，不回显服务商错误正文或密钥。所有 JSON 文件通过0600临时文件、fsync和同目录rename保存。

本机单进程存储，不支持多进程共享目录。运行 CLI 前停 Web 服务或指定独立目录；后续公开部署应引入数据库事务、认证、预算与生产服务器。HTTP标准库服务只面向localhost。
