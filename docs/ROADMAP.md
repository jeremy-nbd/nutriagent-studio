# 后续迭代

## 第一版：可演示的任务闭环（已实现）

合成饮食记录、确定性计算、份量澄清、报告版本、SSE 轨迹、失败恢复、Markdown 与打印 PDF、可配置真实模型工具调用。

## 第二版：真实营养分析输入

1. 用独立来源、可公开使用的食物营养库替换示例参考表，记录许可和每100g口径。
2. 支持用户手动录入多种食物和餐次，先完成输入校验与记录编辑。
3. 接入图片识别，只把识别结果当候选，让用户核对食物和份量。
4. 实现向量召回、重排、原料身份过滤与来源证据；没有命中时明确无法计算。
5. 用标注样本评估身份匹配、份量误差、延迟和调用成本，不用单元测试数量代替准确率。

## 第三版：报告交付与公开展示

1. 基于结构化事实生成报告正文，保留段落级引用，检查引用是否支持结论。
2. 服务端 PDF 渲染与资源回收，增加报告内容和分页回归样张。
3. 公开展示前加入访客演示隔离、登录、速率限制、调用预算和数据库存储。
4. 补录个人项目讲解视频，核实职责与原业务项目贡献，整理求职案例页。

这些是计划，不作为当前功能展示。
