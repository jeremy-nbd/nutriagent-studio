## 下一步：提高营养可靠性

1. 引入有明确许可和口径的营养数据库，用匹配证据替代模型每100克参考估算。
2. 建立真实食物标注样本，评估食物身份、份量误差、隐藏配料、调用延迟与成本。
3. 支持不重新调用模型的食物名称修正、手动新增食物、记录日期调整与软删除恢复。
4. 支持多图、餐前餐后对比、个人目标和长期记录导出。
